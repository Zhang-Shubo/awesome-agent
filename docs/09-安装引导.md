# 09 · 安装引导(从零到面板可用)

> 假设你是一台干净的机器、之前从没装过本项目。按顺序走完每一步,每步末尾都有**验证命令**——
> 验证不通过就不要进下一步。全程约 30–60 分钟(不含可选的对外发布)。

## 第 0 步 · 准备一台机器

- **个人电脑**(Mac / Linux)或**云主机**都行。个人电脑注意:休眠时外部无法访问,常驻服务要么关休眠、要么接受"人在服务在"(两条路线的取舍见 [docs/00](00-依赖清单.md))。
- 需要的基础软件:**git** 和 **Node ≥ 20**(本项目零依赖,Node 自带的就够)。

```bash
git --version && node --version    # 验证:两个都有输出,Node ≥ v20
```

## 第 1 步 · 配置 AI(Claude Code)

这是 agent 的大脑:日常开发、面板"填链接自动登记 APP"都靠它。

1. 安装 Claude Code CLI(任选其一):
   ```bash
   npm install -g @anthropic-ai/claude-code
   # 或官方安装脚本: curl -fsSL https://claude.ai/install.sh | bash
   ```
2. 首次运行 `claude`,按提示用你的 Claude 账号登录(需要付费订阅或 API 额度)。

```bash
claude -p '只回复 ok'    # 验证:输出 ok(headless 模式可用,面板的链接解析依赖它)
```

## 第 2 步 · 配置 GitHub

所有代码(公共脚手架、你的私有项目、记忆)都放 GitHub。

1. 注册/登录 GitHub 账号;
2. 安装 gh CLI 并授权:
   ```bash
   brew install gh        # Linux 参考 https://cli.github.com
   gh auth login          # 选 GitHub.com → HTTPS → 浏览器授权
   ```
3. **推荐 HTTPS + gh 凭证**而不是 SSH key——机器上有多个 GitHub 账号时,SSH key 只能绑一个账号,容易出现"推错身份被拒";gh 凭证跟着 `gh auth login` 的账号走,不会错。

```bash
gh auth status    # 验证:显示已登录的账号,token scope 含 repo
```

## 第 3 步 · 获取并初始化本项目

1. **Fork** 本仓库到你的账号(登记簿、文档都会长成你自己的),然后 clone:
   ```bash
   gh repo fork Zhang-Shubo/awesome-agent --clone ~/my-software/awesome-agent
   cd ~/my-software/awesome-agent
   ```
2. 运行交互式初始化(幂等,可反复运行):
   ```bash
   ./init.sh
   ```
   它会依次:问基础配置(agent 根目录、域名、面板端口)→ 收 GitHub token → 生成 `config.env`(chmod 600,已 gitignore)→ Cloudflare 授权(没域名可跳过)→ 建好 `$AGENT_ROOT` 目录框架(默认 `~/agent`,见 [docs/07](07-目录框架.md))。
3. 不想交互也可以手动:`cp config.env.example config.env` 后按注释填,至少填 `AGENT_ROOT`。
4. 清空示例登记:`registry/` 里保留 `README.md` 和 `_example.md`,删掉其余条目,从零登记你自己的。

```bash
ls -l config.env && ls ~/agent    # 验证:config.env 存在(-rw-------),~/agent 目录已建
```

## 第 4 步 · 建私有工作区仓库

你的私有登记簿、个人配置放 `~/agent`,做成**私有仓库**同步——公共库永远不放个人数据。

```bash
cd ~/agent && git init
cat > .gitignore <<'EOF'
# 以下目录各自是独立 git 仓库,绝不并入工作区仓库
projects/
memory/
skills/
.DS_Store
EOF
mkdir -p registry/agents
git add -A && git commit -m "init: 私有工作区"
gh repo create agent-workspace --private --source . --push
```

要点:`projects/`、`memory/`、`skills/` **必须留在 .gitignore 里**——它们每个都是独立仓库(docs/07 铁律),嵌套进来会互相污染。

```bash
gh repo view agent-workspace --json visibility -q .visibility    # 验证:输出 PRIVATE
```

## 第 5 步 · 启动面板

```bash
cd ~/my-software/awesome-agent
node web/server.mjs    # → http://127.0.0.1:8787
```

打开浏览器:

- 面板是"启动台":**APP** 和 **Agent** 两组图标,悬浮看详情,点击进入;
- 右下角 **✏️ 编辑模式**:新增 APP 只填一个链接(仓库或服务地址),claude 读取后自动生成名字/图标/简介写入**私有登记簿**(`~/agent/registry/`,不进公共库);删除同理只动私有登记簿;
- 右下角 **🌙/☀️** 切换亮暗;
- 想改前端样式:`cd web-react && npm install && npm run build`,server 自动优先托管构建产物;不构建则用 `web/static` 零依赖版。

```bash
curl -s 127.0.0.1:8787/api/apps | head -c 80    # 验证:返回 {"ok":true,...}
```

## 第 6 步(可选) · 对外访问

面板与所有服务**只监听 127.0.0.1**(铁律),对外发布走 Cloudflare:

1. 一个域名,DNS 托管到 Cloudflare([docs/00](00-依赖清单.md) 第 3 项);
2. `cloudflared` 隧道 + Access 鉴权,**Access 先于 DNS** 配置([docs/04](04-隧道与鉴权.md));
3. 面板子域名用 `config.env` 里的 `PANEL_HOST`。

没有域名不影响本地使用,这步可以以后再做。

## 第 7 步 · 创建你的第一个项目

按 [docs/08 项目创建流程](08-项目创建流程.md) 走:定**名字/域名/图标**三要素 → 拷 `templates/` 骨架 → 本地跑通 → 部署 → 登记。样例参考 [info-feed](https://github.com/Zhang-Shubo/info-feed)(零依赖 RSS 时间线,就是按这条流程建的)。

## 速查:装完后的样子

| 位置 | 内容 | git |
|------|------|-----|
| `~/my-software/awesome-agent` | 公共脚手架(fork):docs、templates、公共登记簿、面板 | 你 fork 的公共仓库 |
| `~/my-software/awesome-agent/config.env` | 真实配置 | gitignore,永不入库 |
| `~/agent` | 私有工作区:私有登记簿 registry/ | 你的 agent-workspace 私有仓库 |
| `~/agent/projects/<name>` | 每个项目 | 各自独立仓库 |
| `~/agent/memory` `~/agent/skills` | 记忆 / 通用 skill | 各自独立仓库(用到时再建) |
