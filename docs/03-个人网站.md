# 03 · 个人网站

> Docusaurus 静态站,部署在 Cloudflare 上。它是 agent 成果的**对外出口**:博客、项目索引、工具门户。

## 技术栈

- **Docusaurus 3 + React + TypeScript**:博客(支持数学公式 remark-math/rehype-katex)+ docs + 自定义页面。
- **Cloudflare Workers static assets 部署**:一个 `wrangler.jsonc` 指到构建产物即可:

```jsonc
{
  "name": "mysite",
  "compatibility_date": "2026-01-01",
  "assets": { "directory": "./build" }
}
```

```bash
npm run build && npx wrangler deploy
```

## 三个核心页面

### 1. 博客

写作规范(写进站点的 CLAUDE.md,约束 agent):

- **日期必须用当天实际日期**,frontmatter `date` 与目录名前缀一致——防止 AI 编造或用占位日期;
- 配图走 R2 公开域,路径规范见 [02-云存储](02-云存储.md)。

### 2. `/projects` 项目索引

一个数组驱动的卡片页,每个项目一条记录:

```ts
{
  name: 'my-project',
  status: 'running',          // 'running' | 'api'(公开API) | 'archived'
  statusLabel: '运行中',       // 运行中 / 开源 / 公开 API / 已结项…
  private: true,              // 私有仓加 🔒 徽章;公开仓删掉此行
  description: '如实但概括,不暴露内部路径 / 设备 IP / 私有策略细节。',
  tech: ['Node (零框架)', 'SQLite'],
  // href: 'https://github.com/<you>/<repo>',  // 仅公开仓:标题变链接
  // domain: 'xxx.example.com',                // 仅公开服务
}
```

字段口径:**私有项目**不放 href/domain;**公开仓**放 href、statusLabel 用「开源」;**公开服务**用 `status: 'api'` + domain。项目状态变化时把卡片从 `running` 挪到 `archived`。

### 3. `/tools` 工具门户

自建服务的入口页,一张卡片一个工具,页面直白写明鉴权方式(「全部经 Cloudflare Access 统一鉴权——首次邮箱验证码登录,之后 30 天免登录」)。

`/projects` 是**做过什么**(登记一切项目),`/tools` 是**能用什么**(只放有域名的服务)——两个页面,别混。

## 「一处变三处同步」登记法

网站是三处登记的最后一环。每个新项目:

```
① 知识库项目文档 → ② 状态总表加一行 → ③ /projects 加卡片 + 部署
```

已知坑:

- **push ≠ 发布**:静态站靠 `wrangler deploy` 上线,只 `git push` 线上不变,两个都要做;
- 部署后验证 `curl -s https://example.com/projects/ | grep <name>`(注意结尾斜杠,否则 301 grep 不到);边缘缓存可能短暂命中旧页,几秒后自愈。
